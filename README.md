# 祖仁泽个人镜头 · 视频素材库

为个人视频制作积累镜头、图片、动效、音频与拆解笔记。

[在线素材库](https://zurenze1.github.io/zurenze-personal-lens/) · [个人网站](https://zurenze1.github.io/zurenze-personal-site/)

初始收录本人已公开的 29 张照片、2 段完整原声视频。没有虚构动效作品、拍摄器材或第三方拆解。

## 功能

- 按素材类型、主题标签筛选，搜索名称、备注与拆解笔记。
- 侧栏快速进入动效、拆解和收藏；支持镜头优先、最近加入、名称排序。
- 宽幅 / 紧凑网格，网格选择保存在浏览器；素材卡片可直接下载取用。
- 大图与原生音视频预览、方向键切换、下载取用、浏览器收藏。
- 导入个人图片、视频与音频；自己的动效视频可归入“动效”。
- 视频拆解笔记：名称、参考视频链接、标签、时间点与制作思路。
- 编辑本地条目、可恢复的回收站、导出素材目录与拆解文字。
- 手机、键盘、系统减少动态与手动关闭动态支持。

## 数据保存

GitHub Pages 托管网站代码与本站初始公开素材。新导入的素材文件与笔记保存在当前浏览器的 IndexedDB，收藏和动态偏好使用 localStorage，不上传到 GitHub，不自动跨设备同步。

清除网站数据、浏览器配置或更换浏览器会失去本地内容。请保留原文件；“导出素材清单”包含目录、标签、来源与笔记，不包含上传素材的二进制原件。回收站可恢复本地条目，不执行永久删除。

参考视频仅保存链接与用户自己的拆解文字，不自动抓取或下载第三方视频。本站没有统计追踪、登录服务或付费功能。

## 本地运行

无需安装依赖。使用 Node.js 22 或以上：

```sh
npm run dev
npm run check
```

预览：http://127.0.0.1:5198。GitHub Pages 使用 main 分支根目录。

本地服务器还会只读展示上级 `shots/M001-paper-fan` 中已保存的拆解与可复用动效。扫描 `reusable-personal/` 与 `reusable-personal-v2/` 顶层实际存在的非空 MP4，分别标为“原纸卡版”和“真实照片版”，保留旧版条目 ID。该挂载仅绑定本机 127.0.0.1，运行时读取；M001 参考、关键帧、私人来源档案不复制进本仓库，GitHub Pages 不显示这些本地条目。

## 更新公开素材

修改 `assets/library.json` 与 `index.html` 的静态卡片、内嵌 `asset-data`。图片在 `assets/images/`，视频在 `assets/video/`。浏览器本地导入不会直接修改仓库。

网页图片为 700px/1600px WebP 派生文件，已移除原图元数据，保留自然色彩。部分个人照片由同行者拍摄；未经许可，不得转载人物影像。源码可阅读和学习，个人照片与视频不授予其他用途授权。

采用 `website-craft` 的素材盘点、内容组织、媒体交互与发布验收经验。2026-10-07 改版实际参考 [XCYJ 镜头库](https://shots.xiaochens.com/) 的侧栏、分类筛选和预览卡片结构；采用自己的墨绿底色、浅橄榄强调色、中文宋体标题与真实个人素材，未复制其作品、代码或视觉资产。
