# 祖仁泽的镜头库

为个人视频制作积累镜头、图片、动效、音频与拆解笔记。

[在线素材库](https://zurenze1.github.io/zurenze-personal-lens/) · [个人网站](https://zurenze1.github.io/zurenze-personal-site/)

初始收录本人已公开的 29 张照片、2 段完整原声视频。没有虚构动效作品、拍摄器材或第三方拆解。

## 功能

- 按素材类型、主题标签筛选，搜索名称、备注与拆解笔记。
- 侧栏快速进入动效、拆解和收藏；支持镜头优先、最近加入、名称排序。
- 宽幅 / 紧凑网格，网格选择保存在浏览器；素材卡片可直接下载取用。
- 大图与原生音视频预览、方向键切换、下载取用、浏览器收藏。
- 导入个人图片、视频与音频；自己的动效视频可归入“动效”。
- 视频拆解笔记：名称、参考视频链接、标签、时间点与制作思路。
- 编辑本地条目、可恢复的回收站、导出素材目录与拆解文字。
- 手机、键盘、系统减少动态与手动关闭动态支持。

## 数据保存

GitHub Pages 托管网站代码与本站初始公开素材。新导入的素材文件与笔记保存在当前浏览器的 IndexedDB，收藏和动态偏好使用 localStorage，不上传到 GitHub，不自动跨设备同步。

清除网站数据、浏览器配置或更换浏览器会失去本地内容。请保留原文件；“导出素材清单”包含目录、标签、来源与笔记，不包含上传素材的二进制原件。回收站可恢复本地条目，不执行永久删除。

参考视频仅保存链接与用户自己的拆解文字，不自动抓取或下载第三方视频。本站没有统计追踪、登录服务或付费功能。

## 本地运行

无需安装依赖。使用 Node.js 22 或以上：

```sh
npm run dev
npm run check
```

预览：http://127.0.0.1:5198。GitHub Pages 使用 main 分支根目录。

本地服务器还会只读展示上级 `shots/M001-paper-fan` 中已保存的拆解与可复用动效。按已选最终版与排除规则读取实际存在的 MP4；M001仅展示真实照片最终版。该挂载仅绑定本机 127.0.0.1，运行时读取；M001 参考、关键帧、私人来源档案不复制进本仓库，GitHub Pages 不显示私人参考与制作档案；完成动效以经过验证的公开目录为准。

## 更新公开素材

修改 `assets/library.json`，运行 `npm run build` 自动同步静态卡片与内嵌目录。图片在 `assets/images/`，视频在 `assets/video/`。浏览器本地导入不会直接修改仓库。

网页图片为 700px/1600px WebP 派生文件，已移除原图元数据，保留自然色彩。部分个人照片由同行者拍摄；未经许可，不得转载人物影像。源码可阅读和学习，个人照片与视频不授予其他用途授权。

采用 `website-craft` 的素材盘点、内容组织、媒体交互与发布验收经验。2026-10-07 改版实际参考 [XCYJ 镜头库](https://shots.xiaochens.com/) 的侧栏、分类筛选和预览卡片结构；采用自己的墨绿底色、绿色强调色、中文宋体标题与真实个人素材，未复制其作品、代码或视觉资产。


## 动效分类与发布（1.3.0）

用途分为开场与身份、文字与观点、信息展示、转场与衔接、镜头与氛围、收尾与引导。内容主题单独记录 AI工具／趋势／教程／创作，以及自我介绍、儒家、佛学、道家、个人成长、思考表达、生活记录、工作分享；同一动效可以适用于多个主题。画幅独立筛选。详见 [分类与流程](docs/分类与流程.md)。

当前公开 M001 真实照片卡片与 M002 力量金句 4K 的最终选用版 MP4、拆解页和干净可改源包。该版本已由祖老大明确满意并用于个人影片最终成片，标为“已满意 · 已用最终版”。原纸卡版已从公开目录和取用入口撤下，历史工程仅作本地档案。

**唯一编辑源**为 `assets/library.json`，不再手工同步三个目录副本。修改后依次运行 `npm run build` 与 `npm run check`，生成静态卡片和内嵌目录。公开源包固定版本单独保存；重新制作请使用新版本号。

后续对话中提交的新视频，由 motion-library 工作流完成入库、去重、复刻、验证、Eagle同步与经确认的本仓库发布；网页导入仍为浏览器本地保存。

## 最终版本的公开确认

独立动效完成后，先准备可审阅的 MP4、封面、公开拆解和干净可改源包，再由祖老大确认具体版本与公开内容。实际采用或审美满意不代替上传同意；当次已经明确同意上传的具体范围不重复询问。发布前核对版本、成片使用记录和文件哈希，完成公网播放和下载验证后登记结果。原参考、制作日志、未采用候选与完整影片留在本地。

网页“导入素材”只保存在当前浏览器。待发布检查只核对本地明确记录和既有公网素材，不自动上传、替换或撤下文件。仓库技术地址保留 `zurenze-personal-lens`，标题、README 与仓库说明统一为“祖仁泽的镜头库”。

每个镜头只展示最终选用的一版。明确不要的版本记录在 `assets/publication-policy.json`，不得重新加入；经确认更换最终版时撤下旧入口，保留本地制作历史。

## 绿色星球主题（1.4.0）

2026-10-08 按祖老大确认的绿色星球方向改版。首屏使用 imagegen 生成的原创无水印星球图，WebP 约 149 KiB；以缓慢推移、柔和光晕和少量星点营造空间感。素材区采用深绿底与清晰的原色预览。没有引用参考视频文件或水印资产。

手动关闭动态、系统减少动态时展示静态画面；首屏离开视口、标签页隐藏或打开预览时暂停背景。手机保留静态星球构图和轻量光晕。既有搜索、筛选、收藏、预览与下载流程保持可用。

## 星球交互（1.5.0）

首屏响应鼠标位置与拖动：星球和星点产生不同层次的视差，光晕跟随指针；点击空白星空出现扩散光波。“换个视角”提供键盘和手机都可用的操作入口。页面进入时标题与星球短暂入场，素材卡片进入视口时逐个浮现；桌面卡片随指针轻微倾斜并显示局部光感。触屏横向轻拖可改变视角，纵向仍正常滚页。

动态开关和系统减少动态偏好优先；关闭后首屏回到静态视角，搜索、筛选、预览与下载仍可使用。首屏离开视口或打开预览时暂停背景运算，素材卡片交互独立工作。主题CSS与JS使用版本参数，避免更新后仍加载旧交互代码。

本项目每小时待发布检查已暂停；后续独立动效按具体版本取得上传同意，网页主题改版不改变该规则。
